# 兴康明 PC 患者端

独立网站工程，使用已确认的蓝色医疗官网 UI。不是 HTML 设计稿，不加载设计稿的演示脚本；业务数据来自既有 `/api/v1` 接口。小程序代码与原设计稿未修改。

## 本地运行

需要 Node.js 22.20+（或 24+）和运行在 `127.0.0.1:5005` 的现有后端。

```sh
cd hanjing-patient-web
npm ci
npm run dev
```

访问 `http://127.0.0.1:3003/`。开发代理只连接本地后端，不回退正式环境。

```sh
npm run build
npm test
```

`dist/` 是正式构建产物。`prepare:assets` 只读取 `UI` 的图片以及小程序录音页中的纯 PCM 分析函数，生成本项目的静态资源和独立 Worker；不会修改原文件。

## 实现范围

- 游客首页、门店、医生介绍与排班选择。
- 手机号密码登录及本地开发诊断登录。
- 预约创建、列表、详情、取消、改期、就诊评价。直接保留后端状态；不新增预约 API、不新增状态、不接入 PC 微信支付。
- ESS 问卷与记录；浏览器麦克风录音、实时电平、复用小程序算法分析及保存报告。
- 社区列表、搜索、详情、发布、评论、回复、点赞、收藏、举报、复制分享链接。
- 商品分类、搜索、详情、下单、订单详情、取消、确认收货、退款申请及物流信息。所有金额来自后端；不调用支付接口。
- 个人资料、家庭成员、病历与图片附件、通知、账号密码、会员权益、优惠券及积分兑换。
- 治疗记录、睡眠报告、佩戴打卡、阻鼾器、调整/维护记录、使用反馈。
- 推广概览、邀请信息、团队、佣金、银行卡提现申请与记录；在线客服消息。
- 科普直播信息与后端提供的普通视频回放。

## 登录方式

PC患者端仅保留手机号密码登录；本地开发诊断入口保留。微信扫码入口、授权回调交换、账号关联及PC专用扫码后端路由已移除，无需配置网站应用AppID或AppSecret。

现有接口不支持独立PC注册：小程序注册依赖微信授权；密码登录只验证已有账号；患者短信接口尚未接入真实服务。新增PC注册需单独实现并复用现有用户/本人档案逻辑。

## 平台边界与部署

- 微信小程序手机号授权、实名认证与微信直播插件不能在普通 PC 网页直接调用；相应页面明确引导到小程序，没有模拟成功。普通 HTTPS 回放链接可以在 PC 播放。
- 录音必须运行于 HTTPS（本地 localhost/127.0.0.1 除外），需授权麦克风。实时显示真实录音电平 dBFS，不冒充校准环境声压。报告的估算 dB 沿用原有算法；不会因 PC 开发改变小程序算法。录音推断不是医学诊断，也不能据此确诊呼吸暂停。
- 登录凭据保存在独立 `sessionStorage` 中，关闭当前浏览器会话后需要重新登录，不复用运营或推广后台的凭据。
- 生产部署使用静态服务器提供 `dist/`，同域反向代理 `/api/` 与 `/uploads/` 至现有后端。参考 `deploy/nginx.conf.example`；开发服务器不能作为正式服务器。
- 不修改根 Docker Compose、原小程序域名、原后台部署或数据库结构。更新前后端后，PC微信扫码登录接口不再提供。

## 验证

- `npm test`：模板结构、API字段契约及密码登录检查。
- `npm run test:browser`：需单独 headless Chrome 在 9337 提供 CDP；脚本拒绝普通用户浏览器。先访问本地真实公开接口，再在隔离标签页中替换 API 验证交互；不会用夹具冒充真实数据库验收。
- `PC_RUN_LOCAL_INTEGRATION=1 node tests/local-integration.mjs`：显式执行本地真实接口集成。只支持本地数据库；创建唯一临时用户、门店、医生、排班及业务记录，并在 finally 中按实际 ID 清理。不能用于正式环境。
- 测试记录在 `tests/patient-web/implementation-2026-10-27.md`。开发自测不替代独立回归；实际微信账号扫码和物理麦克风准确性仍需验收。

## 本地模拟登录

`npm run dev` 启动后，在 `http://127.0.0.1:3003/#/login` 或 localhost 登录页可点击“本地模拟登录”。后端需 `NODE_ENV=development`、`ENABLE_LOCAL_DEV_LOGIN=true` 并连接本地数据库。复用小程序独立测试账号，走正常本地业务API；不绑定真实微信，不更改现有患者身份或权限。入口仅Vite开发模式且浏览器为本机地址时可见；生产构建不显示。本地会话使用独立标记，非本地开发环境不能恢复。模拟登录不替代真实微信授权及支付验收。

## 治疗板块

治疗总览对齐小程序：无治疗记录时仍展示日历、统计及功能入口，有就诊人档案即可打卡，无需绑定设备。完整月历、7/30天趋势、睡眠报告、时间线、医嘱与设备调整均使用既有患者API，并在导航中携带所选就诊人。佩戴表单支持0–10疼痛评分、多部位选择和原舒适度映射。验证范围见 tests/patient-web/treatment-parity-2026-10-28.md（仓库根tests目录）。

佩戴打卡采用当前页右侧抽屉，旧 `#/wearing` 链接自动转入治疗页并打开抽屉。专项浏览器自测：在隔离 Headless Chrome CDP 9338 下执行 `node tests/wearing-drawer-browser-check.mjs`。
