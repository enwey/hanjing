# 兴康明 PC 患者服务设计稿

主题配色已对齐小程序 `app.wxss`：主色 `#3B6BF5`、浅蓝 `#EEF4FF`、深蓝 `#1A3580`，配合原有灰阶；保留第二轮已确认的 C 端布局、文字与游客流程。

## 第四轮功能校正（当前版本优先于下方早期设计说明）

按现有小程序源文件修正功能含义与名称。网站主导航恢复“首页 / 社区 / 治疗 / 商城”，个人服务为“我的”。首页使用现有品牌文案、立即预约、预约记录、睡眠评估、治疗追踪、我的档案、推荐医生和我们的门店；保持游客首页及蓝色 C 端风格。

| 模块 | 校正依据 | 当前设计 |
|---|---|---|
| 社区 | `pages/appointment/index`、`pages/community/*` | 患者社区/医患社区；热门、最新、专家；帖子、评论、点赞、收藏、分享、举报，不用课程替代 |
| 发帖 | `pages/community/publish/index` | 原有 6 分类与 6 标签；标题 40 字、内容 1000 字、最多 3 标签，移除原稿虚构的图片上传 |
| 直播 | `pages/live/*` | 直播中心、直播详情；全部/直播中/预告/回放、微信直播间、直播好物；PC 播放承接待确认 |
| 商城与订单 | `pages/product/*`、`pages/order/*` | 默认医疗器械/配件耗材/服务套餐；待付款/待取货/待发货/已发货/已完成；选择商品对应详情，订单操作按样例状态展示 |
| 设备 | `pages/profile/device-manage/*` | 佩戴数据、维护记录、使用反馈；不把维护历史替换为护理文章，反馈保留评分、历史和回复 |
| 治疗 | `pages/treatment/*` | 治疗追踪、打卡日历、睡眠趋势、睡眠报告、医嘱建议、设备调整、医患社区 |
| 就诊人及账户 | `pages/profile/*` | 原有个人信息/账号安全及菜单；就诊人补所属诊所、关系、病历号、地址，身份证不改为强制必填 |
| 分销 | `pages/distribution/*` | 分销中心、团队成员、提现申请、分销规则；银行卡字段，微信零钱显示未开通 |
| 协议与登录 | `pages/auth/*` | 协议展示现有原文及适用范围提示；保留手机号授权身份体系，PC 授权方式待确认，不假定扫码接入 |

`js/pc-mini-reference.js` 保存 59 个页面的来源路径与固定标题，标题直接引用来源快照。业务记录、医生、商品及金额仍为明确标注的演示数据，不声称来自实时接口。功能语义校正不等于已实现全部正式业务状态。

## 打开方式

在浏览器中直接打开 `PC端全页面设计稿_平铺版.html`，无需安装依赖或启动后端。

- 默认直接展示 C 端网站，面向游客，顶部为首页、社区、治疗、商城与登录入口。
- 右下角“全部页面”仅用于设计验收，展示各页面画板；个人页标记为登录后示例。
- 不在网站界面显示小程序访问路径、开发目录或路由对照。
- 59 个原路由的内部映射仍保留在设计脚本中，不作为用户导航。

## 第二轮修订：游客优先的 C 端体验

2026-10-26 按用户反馈重做首页。去除首屏的姓名、佩戴统计、预约数据卡与后台式外框，改为品牌展示、睡眠困扰引导、医生介绍、服务过程和健康内容。公开内容不依赖登录；游客可以先选择门店、医生与时段，到确认预约时再登录。个人预约、档案、设备、订单、报告与推广数据仅在登录后示例中展示；退出后回到游客首页。

“新建预约”改为“预约就诊”。个人记录仍保留在“我的健康”里，而不是摆在所有人的首页。登录状态只在当前原型内存中模拟，不属于真实安全鉴权。

整体为患者使用的桌面服务平台，不是运营后台或推广员独立后台。顶部导航承载主要功能，页面采用宽屏主次分栏、横向流程、数据趋势、商品网格和社区内容布局。

## 可以演示的操作

预约选择会将门店、医生、日期、时段、就诊人带到确认和成功页；ESS 问卷须完成八题并计算演示总分；录音页有模拟计时及模拟分贝；支持商品分类、部分状态筛选、点赞、表单必填校验、客服本页消息、打卡及账户弹窗。

## 明确边界

- 只修改 UI 设计及对应自检记录，没有修改小程序、运营端、推广端、后端及数据库业务代码。
- 所有人物、金额、健康指标均为演示，不访问接口、不持久化用户资料、不产生真实业务。
- 页面覆盖不代表生产功能迁移完成。部分筛选为状态展示样例，表单提交仅提示演示完成，不形成完整业务状态机。
- PC 手机号授权承接方式仍需确认。账号安全保留小程序密码设置与实名认证入口，不据此新增 PC 密码登录。
- 邀请码、登录码与地图为明确标注的占位；不扫码、不定位、不录音、不支付、不提现、不上传附件。
- 声音仪表与报告图均为模拟展示，不能判断实际声级或提供医学结论。
- 协议展示小程序现有原文，PC 端适用范围仍须确认，不将原文直接视为已生效的 PC 条款。
- 保留现有项目考拉 Logo，封装到本目录的 SVG 图片中，设计预览不依赖业务项目的资源路径。
