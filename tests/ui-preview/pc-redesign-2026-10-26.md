## 第六轮：患者口吻、slogan 对齐与真实素材

- 用户要求：slogan 以小程序 `mp-weixin-rewrite` 原文为准；文案改为面向患者，不用开发者口吻；首页只承担展示与导流，功能在后续页面；选用 `ui/素材/` 实拍，必要时优化或重绘但必须真实。
- slogan：对照 `mp-weixin-rewrite/pages/auth/login.js` 的 `brandSlogan` 与首页 WXML，保持「专注睡眠呼吸健康 · 让每一个夜晚安宁无声」，首页两行排版、间隔点保留，未改写。
- 文案：首页、门店、医生、预约确认、商城、报告、佩戴记录、维护、会员、社区、分销、提现及登录/实名/取消等弹窗中患者可见的“示例 / 演示 / 样例 / 原型 / 版式示例”等工程口吻全部改写为患者可读表达；医疗免责统一为“不作为诊断结论，具体以医生面诊为准”一类自然表述；图片免责改为“图片为诊所实景……不替代医生面诊与诊断”。
- 首页导流（CDP 实测 8 条）：Bento 主卡→门店；三张导流卡→睡眠评估 / 治疗追踪 / 我的档案；环境区“查看门店与路线”→门店；Hero 主按钮→门店；医生“医生详情”→医生页；底部 CTA→门店，全部命中目标页。
- 素材选型：从 `ui/素材/` 25 张实拍中选用入口（266）、走廊候诊与科普墙（258）、品牌墙（263 重裁）、科普墙（251 重裁）、诊室（254）、设备间（255）、定制矫治器（279）。无医生人像，首页医生区改为文字名录（序号 / 姓名 / 专长 / 出诊 / 患者视角配文），不生成合成人像。
- 图片处理：品牌墙重裁保留 logo 与中英文名称；科普墙收紧到 slogan + 心电图形 + 二维码；走廊 +7% 亮度、-5% 饱和；入口 +6% 亮度；诊室 -10% 饱和，使三张环境图色调统一；门店页缩略图改 4:3，避免标识被裁；矫治器大图补实拍说明（`.care-caption`）。
- 其他修复：默认门店改为真实门店；门店页由多城市样板改为单家真实门店（下李朗路 73 号 7 栋）；商城三卡图片固定 236px 高度；桌面 H1 断行；移动端 `.hero-meta` 改三列网格，消除换行残线。
- 已执行：`node --check ui/js/pc-redesign.js` 通过；`node tests/ui-preview/pc-redesign-check.mjs` **110 项通过、0 失败**；1440 / 1024 / 390 截图（禁用缓存、阻断 Google Fonts）确认 `scrollWidth == innerWidth`、无坏图、医生名录与 Bento 布局正常。
- 边界：原型数据仍为静态占位；报告、录音等页面数值未接真实设备；未逐页人工复核 59 页全部状态。

## 第五轮：按开源设计规范重构视觉

- 用户反馈：上一版视觉不合格，要求先寻找开源设计 skill，再依 skill 规范重做。
- 依据：项目内安装 `frontend-design`（anthropics/skills）与 `high-end-visual-design`（Leonxlnx/taste-skill），按其双圈包裹、自定义缓动、GPU 安全动画、禁模板化配色等规范执行。
- 设计方向：深松绿 / 纸白体系（取自“睡眠与呼吸=夜与氧”，不使用互联网医疗蓝）；宋体标题 + 无衬线正文；首页 Editorial Split + 非对称 Bento 服务区 + 滚动入场 + 纸感颗粒。
- 改动范围：仅 `ui/` 下设计稿入口、`css/pc-redesign*.css`、`css/pc-consumer.css`、`js/pc-redesign.js`；未改业务代码。原稿保留为 `PC端全页面设计稿_平铺版.原稿.html`。
- 本轮发现并修复：内页内容贴左被裁（`.app-body` 未居中容器）；Bento 主卡底部留白（`margin-top:auto`）；移动端导航未换行（`.top-nav` 基础 `flex:1` 覆盖 `width:100%`）；Google Fonts 同步加载在受限网络下阻塞脚本导致页面空白（改为非阻塞加载 + 系统字体兜底）；Hero 满宽底色伪元素 `inset:0 -100vw` 造成 `app.scrollWidth` 溢出（改为区块自身满宽 + 内边距留白）；进度条宽度动画改为 `transform:scaleX()`。
- 已执行：`node tests/ui-preview/pc-redesign-check.mjs` **110 项通过、0 失败**（含 59 路由、模板闭合、1536/1280/1024 无横向溢出、交互与小程序文案对照）。
- 视觉核对：CDP 真实视口截图（1440×900、390×844，禁用缓存并模拟 `prefers-reduced-motion`）核对首页、门店选择、商城、问卷、报告、全部页面模式；390 宽实测 `documentElement.scrollWidth=390`、`app.scrollWidth=390`，导航换行正常。
