# PC治疗板块与小程序对齐

- 日期：2026-10-28
- 状态：待回归
- 对照：mp-weixin-rewrite/pages/treatment/ 下的首页、calendar、sleep-trend、sleep-report、timeline、doctor-advice、adjust-detail。
- 目标：PC治疗页不因无绑定记录而整体提前返回；保留真实空态，显示日历、统计与功能入口，使用既有业务接口。

## 实现范围

| 小程序功能 | PC实现 |
| --- | --- |
| 治疗状态/设备/医生/初配日期/依从率 | 治疗总览卡；无记录显示未开始与预约入口，不伪造治疗数据 |
| 最近7天打卡/痛感颜色/4项统计 | 日历条、0–24h佩戴柱、无痛/轻/中/重痛图例、本周佩戴/平均时长/平均痛感/连续天数 |
| 完整日历 | treatmentCalendar，按月前后切换，可点击已到日期进入佩戴录入 |
| 睡眠趋势 | treatmentTrend，7/30天切换，真实逐日佩戴时长与疼痛 |
| 睡眠报告 | treatmentReport，复用睡眠报告接口的评分、依从率、平均时长及每日数据，不新增诊断算法 |
| 治疗时间线 | treatmentTimeline，真实就诊/治疗事件 |
| 医嘱建议 | treatmentAdvice，诊断、治疗方案、医生建议、复诊日期 |
| 设备调整 | treatmentAdjust，当前前移量、下次调整和历史 |
| 今日打卡 | wearing，日期/时长/VAS0–10/8类疼痛部位多选/备注；更新已有当日记录 |
| 社区/设备/病历 | 复用原PC功能入口，保持就诊人参数 |

- 佩戴页有合法就诊人即可提交，无需绑定设备；历史记录可读。舒适度沿用小程序与后端原映射：0→5，1–2→4，3–4→3，5–7→2，8–10→1。
- 每个治疗请求带patientId，所有子功能保留选择；未知/无权的就诊人不静默回退到其他患者。原render的异步代次/取消机制保持，错误不冒充空记录。
- 不修改小程序、后端数据库和接口；不注入假治疗记录。

## 未绑定也可打卡：修正与验证

- 当前状态：待回归。

- 修正：首页及日历的今日打卡入口不再检查record；日历所有已到日期可进入打卡；wearing页不再请求治疗记录作为前置条件，直接按patientId加载和保存。暂无治疗记录提示与预约入口保留真实状态，不伪造绑定。
