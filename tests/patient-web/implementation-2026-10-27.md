## 待验收 / 已知平台边界

1. 真实微信扫码：当前后端未配置 `PC_WEB_ORIGIN`、`WECHAT_WEB_APP_ID`、`WECHAT_WEB_APP_SECRET`，实际请求返回 503。需要微信开放平台网站应用、与小程序关联的 unionid 体系及授权回调域名；不能将小程序 AppID 直接当网站应用使用。
2. 真实账号的扫码与首次关联、外部 HTTPS 域名部署尚未验收。
3. 电脑麦克风没有声压校准，实时 dBFS 是录音电平；原算法输出的 dB 为估算值，不宣称真实环境声压，不能用于确诊呼吸暂停。物理麦克风、实际鼾声识别准确性、多浏览器真机未验收。
4. 微信直播插件、微信手机号授权/实名操作保留明确的小程序引导；没有新增替代接口，没有假装网页可直接调用小程序原生能力。
5. 真实支付按用户要求不实现；真实退款、积分兑换、提现和账号关联未对现有业务数据做破坏性验收。对应前端与 API 契约已实现，但不能把隔离交互通过当成真实资金流程通过。
6. 不新增 PC 注册/找回密码接口；未注册/未设置密码的患者须先在小程序完成。
7. 开发自测不替代独立回归或产品验收。
