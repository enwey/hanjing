## 问题清单

### POC-01 关闭分销后仍生成新佣金

- 状态：回归通过（隔离模块）；风险等级：高。
- 现象：佣金生成路径不读取全局分销开关；关闭后仍产生待结算佣金。
- 预期：按全局“启用分销”开关语义，关闭期间不新增分销佣金。
- 实际：实付 10000 分、一级比例 10%、二级 5%，模拟关闭配置下仍写入 1000 分与 500 分佣金。
- 复现：准备有效两级推广关系及参与分销的订单商品快照；将测试配置设为关闭；执行实际 `createPendingDistributionCommission`；检查模拟写入记录，数量为 2 而非 0。
- 证据：`hanjing-clinic-backend/routes/client.js:1444` 佣金函数不检查开关，`:1185` 支付完成路径直接调用；`distribution-ledger.js` 的结算路径及提现路由则检查开关。
- 影响：关闭期间仍累计佣金义务，重新开放后可能进入结算。尚未在真实数据库执行该流程；若产品定义此开关仅暂停结算/提现而允许继续计提，则须业务确认并调整缺陷判定。

### POC-02 取消支付后再次提交会创建第二笔订单

- 状态：回归通过（隔离模块）；风险等级：中。
- 现象：商品结算页取消微信支付后停留原页，再点提交会重复创建订单。
- 预期：同一次结算取消支付后重试，不应无提示创建另一笔相同待支付订单。
- 实际：连续两次提交、每次支付取消，`createOrder` 调用 2 次，支付对象依次为订单 1、2；首次创建的订单没有在页面重试中复用。
- 复现：填写有效地址和数量；提交；模拟支付取消；保持商品及地址不变再次提交；检查创建调用及支付订单 ID。
- 证据：`mp-weixin-rewrite/pages/product/detail.js:483`，每次进入均创建订单，订单 ID 仅存于本次局部变量；结束后解除提交锁。
- 影响：重复待支付订单。后端创建订单会扣减库存，因此存在重复占库存风险；本轮未对真实库存做写入验证。不等同于已发生重复扣款，也不等同于提交中的快速连点缺陷。

### POC-03 推广订单旧响应覆盖较新的结果

- 状态：回归通过（隔离模块）；风险等级：中。
- 现象：页面两次加载的返回顺序反转时，最终显示旧请求的数据。
- 预期：后发起的加载结果生效后，不被先发起、后返回的请求覆盖。
- 实际：先请求 A、后请求 B；B 返回 `new` 后 A 返回 `old`，最终页面订单 ID 为 `old`。
- 复现：对同一页面调用两次 `loadPage`；延迟 A；先完成 B，再完成 A；检查 `data.orders`。
- 证据：`mp-weixin-rewrite/pages/distribution/orders/index.js:76`；返回数据直接覆盖订单及汇总。
- 影响：列表与佣金汇总回退到旧状态。本轮只复现请求乱序，没有模拟账号切换，不能据此认定跨账号数据泄露。

## 已执行且通过的隔离检查（16 项）

1. 两级佣金按商品快照比例计算：1000 / 500 分。
2. 实付折扣按比例影响佣金：实付 5000 分时为 500 / 250 分。
3. 实付 0 不生成佣金。
4. 非分销商品不生成佣金。
5. 显式 0 比例快照不回退到非零比例。
6. 顺序重复调用不重复生成佣金（不代表并发幂等通过）。
7. 两级佣金合计不超过实付金额。
8. 无推广关系不生成佣金。
9. 无效收货信息阻止创建订单。
10. 待结算佣金退款仅扣总佣金，不扣可用佣金，并标记退款状态。
11. 已结算佣金退款同时扣总佣金与可用佣金。
12. 未发货、未验配商品退款恢复库存。
13. 已发货商品退款不自动恢复库存。
14. 账本可用余额扣除已支付和已占用提现。
15. 退款后负余额不被隐藏为 0（账本算术验证）。
16. 提现账号输出剔除 `accountNoEncrypted`。
