## 实现

- 自动建立本人档案时复用 users.phone 已有密文；兼容明文输入，但不再对密文重复加密。
- 启动迁移仅检查 source=mini_app、relation=self 的加密患者手机号。只有外层能解密为有效 det: 密文、内层能解密为有效11位手机号时才去掉多余外层；按旧值条件更新，避免覆盖并发修改。
- 正常单层密文、明文、空值、无法解密的值、非本人或非小程序来源档案不变。不修改用户身份、家庭关系或号码实际内容。
- 收银患者搜索结果改为先解密后脱敏，沿用后台已有格式化函数。完整手机号仍通过原有权限校验和审计接口查看。
