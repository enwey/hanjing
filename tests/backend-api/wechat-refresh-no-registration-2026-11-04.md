- 日期：2026-11-04

- 范围：无手机号授权的微信登录请求仅用于已有账号续期；不清理历史患者、不修改手机号授权登录流程。
- 原因：同一接口在 phoneCode 缺失时仍可创建 users 和默认 patients。
- 预期：不存在的账号、缺少已验证手机号的账号返回401；已有已验证手机号账号只签发登录凭证，不补建患者。
- 正式环境记录的实际来源尚未逐条验证；本修复关闭已确认的代码路径，不代表认定截图全部数据由此产生。

## 实现

- 修改 `hanjing-clinic-backend/routes/client.js`：微信身份交换、按 openid 查询后，将缺少 phoneCode 的请求作为兼容旧客户端的续期路径。账号不存在、手机号为空或无 phone_verified_at 时返回401；符合条件时只读取登录响应所需数据并签发凭证，提前返回，不进入注册、合并、会员重算或建档。
- 保留携带 phoneCode 的显式授权流程；不改页面、客户端协议或历史数据。已有手机号但未标记验证的历史账号需要重新授权一次。
- 没有把账号缺失的续期请求转换为新注册，也不根据客户端传入的“续期标记”决定是否允许注册。
