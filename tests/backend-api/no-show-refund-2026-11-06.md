- 日期：2026-11-06

- 问题：自动过期只更新未到诊状态，没有像手动未到诊一样将已收预约费用转入待退款。

## 修改
- db.js：在自动过期预约的同一事务、预约行锁内复用 queueCancelledChargeRefunds；退款准备失败时不会单独提交未到诊状态。
- routes/admin.js：手动未到诊的默认退款原因改为“预约未到诊”，取消预约仍为“预约已取消”。
- 已收独立预约收费单进入 refund_pending，退款记录为 pending；待支付单关闭，免费预约不生成退款。
- 不调用实际退款渠道。现金仍须工作人员确认款项已退还；微信仍须工作人员提交并等待微信结果。
- 历史订单退款代码未修改；复用函数仅操作 appointment_charges / appointment_charge_refunds，不将 orders 转入新的预约退款流程。
- 不追溯修改此前已经处于 no_show 的记录；本次覆盖后续自动过期转换，其已有手动退款入口保留。
