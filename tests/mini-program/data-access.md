## ENV-01：默认本地数据接口不可连接

- 风险：高（限当前本地联调环境，影响首页及业务数据访问；未证明正式环境不可用）。
- 现象：用户反馈小程序获取不到数据。
- 预期：当前所选 API 环境提供可访问的数据接口。
- 实际：本机请求 http://127.0.0.1:5005/health/ready 及 /api/v1/home/stats、/doctors、/stores、/products，5 项均 ECONNREFUSED，没有收到 HTTP 响应。不是服务端返回空数组或 HTTP 401。
- 复现：在当前电脑对上述地址执行 GET；观察连接结果。请求不携带账号凭据，也未访问生产接口。
- 源码证据：common/config/env.js 开发版默认 local，指向 http://127.0.0.1:5005/api/v1；api/request.js 采用当前环境候选地址；首页 loadPage 请求 home/stats、doctors、stores。
- 环境配置模块隔离执行：develop 无覆盖值选择 local；develop 且覆盖 production 选择正式地址；release 选择正式地址。三种输出与代码一致，不代表读取了用户微信存储。
- 影响：若当前小程序使用默认本地环境，无法取得接口数据；首页请求全部失败时代码设置“加载首页失败”并清空医生/门店列表。此页面表现为源码分析，未进行真机视觉复现。

## 辅助证据

- 管理后台 http://127.0.0.1:3000/login 与推广端 http://127.0.0.1:3002/login 均 HTTP 200；只证明前端页面可访问，不证明后端可用。
- 本机 127.0.0.1:3306 TCP 探测 ECONNREFUSED。未确定数据库是否映射其他端口或位于其他主机，不能据此认定 Docker 未运行。
- 后端 .env 文件不存在；未检查远程或容器注入配置，不单独将缺文件判为根因。
- 项目配置 urlCheck=true，私有配置 urlCheck=false；没有读取开发者工具实际生效状态，未确认域名校验故障。
- 未读取 debug_api_env_override 的实际值；若用户选择正式环境，本轮本地探测不能解释其正式接口失败。
- 未操作开发者工具，未访问线上接口，未验证原版 mp-weixin、手机实机或实际账号请求。
