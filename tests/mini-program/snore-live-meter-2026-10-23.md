# 录音页实时电平与分贝显示

- 状态：待回归
- 范围：录音页面实时声音分贝数值与峰值展示，便于用户在录音时与其他专业声级计/分贝检测工具进行实时横向对比；不修改后端报告上传校验或历史报告落库逻辑。
- 换算依据：实时分贝直接复用校准后的标准声学公式 $20 \log_{10}(\text{RMS} / 32768) + 96$ dB SPL，与算法报告保持 100% 相同基准。

## 实现与设计
1. **录音区域增加实时分贝面板**：
   在 `waveform` 与操作按钮之间新增双数值面板，展示“当前分贝”与“最高峰值”（单位 dB），支持用户手持双设备实时比对；
2. **实时计算与高频刷新**：
   `_onRecorderFrame` 在微信 PCM 帧到达时（约 128ms/帧）同步计算该帧 RMS 及分贝值，动态刷新 `currentDecibel`，并持续捕获最高峰值 `peakLiveDecibel`；
3. **状态生命周期管理**：
   - 未开始录音：隐藏面板保持界面清洁；
   - 录音中：实时动态更新当前分贝与峰值；
   - 暂停时：保留当前分贝与最高峰值供对比参考；
   - 停止/重置时：恢复初始态；
4. **严格遵循视觉与无歧义规范**：
   - 无任何多余或容易产生歧义的装饰图标，采用纯净清晰的“当前分贝”和“最高峰值”文字标注与等宽数字展示；
   - 区分符使用精致细线 `meter-divider`；
   - 页面采用弹性纵向滚动与自适应高度，避免不同屏幕尺寸内容碰撞或遮挡。
