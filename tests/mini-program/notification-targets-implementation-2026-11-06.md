# 通知详情与精确定位补齐

日期：2026-11-06
状态：待回归（开发自测完成，独立接口与真机验收由主任务汇总）

## 实现范围

- 新增后端 `notification-details.js`，以当前账号重新检查预约、订单、患者、举报归属，仅返回患者可见字段。
- 通知详情展示实际预约收费/退款单、商城退款状态、指定病历和指定治疗记录、售后处理、随访安排、举报处理结论。不是仅显示消息正文或跳到最新记录。
- 家庭成员客服通知展示就诊人及实际服务回复；只对当前本人会话提供继续咨询入口，避免误跳其他人的会话。图片仅接受上传路径或HTTPS链接。
- 评论通知携带 commentId 后定位、高亮具体评论；已删除/不可见评论提示，不误定位其他评论。
- 病历入口接收 recordId，定位、高亮具体病历；通知内同时直接展示该记录。
- 动作点击重新获取服务器允许的目标，过期目标不再执行。
- 列表使用 snapshotVersion 检测同ID聚合消息的新互动。翻页和返回不推进原始已读快照；全部已读不覆盖更晚版本。单条已读携带所见 changeVersion，避免新点赞被旧卡片操作误读。

## 边界

- 本子任务未通过SQL创建业务数据，也未操作真实业务库。模块投影用mock明确隔离，不冒充真实接口验收。
- 没有控制用户浏览器或微信开发者工具；视觉检查不是微信原生渲染。
- 当前业务没有家庭成员独立客服发送入口，未擅自扩展本人消息接口或权限。已在通知详情安全展示该家庭成员的实际回复，提示联系门店。
- 没有新增退款、售后、举报等业务变更操作；只开放现有合法预约、本人客服入口。
