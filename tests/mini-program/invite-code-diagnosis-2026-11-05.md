## 已确认

- 本地distributors共5条，邀请码缺失0条，小程序码为空或占位4条；这是本地统计，不代表用户生产账号。
- invite页面服务同时请求invite-info及distribution/info，Promise.all任一失败即丢弃全部结果；页面catch仅提示加载失败，不更新邀请码。
- 模拟实际invite-service复现：invite-info已返回有效邀请码，distribution/info失败时仍整体拒绝，导致已有邀请码不能显示。

- 单纯二维码生成失败但接口成功返回时，模拟服务仍保留邀请码，不能把“没有二维码”等同“没有邀请码”。
- 缺少用户当前账号实际请求结果，不能断言生产账号的邀请码未生成。未实际执行真机检查。
