# 临时运行数据清理

状态：待回归

## 范围
- 数据库工具新增独立临时模块，提供患者档案、预约与收费、商城与收银订单、诊疗与佩戴、睡眠评估、交付与售后、推广业务流水、社区互动八项选择。
- 选择后预览实际表名、业务名称、数量和连带更新；输入“确认清理”并点击“立即清理”执行。
- 超级管理员专用，前端隐藏其他账号入口，后端单独校验；不新增通用数据库删除权限。
- 关联删除使用固定表白名单、实际外键和补充业务关系；保留系统表、角色成员、微信通知日志及配置、基础资料和登录账号。不关闭外键，不重置预约流水，不使用 TRUNCATE。
- 患者关联订单包含预约订单、收银 JSON 中的患者订单及该账号没有具体患者上下文的商城订单；其他账号无关订单保留。
- 推广提现无法按订单准确拆分，涉及佣金删除时会将该推广员的完整佣金/提现流水列入预览；推广账号、二维码和绑定关系保留。
- 评估独立清理仅解除预约引用，不删除预约；按剩余记录更新占用、销量、会员等级等，库存不变。
- 不操作外部支付渠道，不删除服务器附件文件；清理记录写入审计日志。
