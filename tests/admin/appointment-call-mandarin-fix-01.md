# 运营后台叫号普通话修复

- 日期：2026-10-23
- 状态：待回归
- 范围：预约列表、候诊队列、诊疗工作台、预约详情的叫号语音

## 问题

原实现只为 `SpeechSynthesisUtterance` 设置 `zh-CN`，未明确选择语音引擎。部分浏览器会继续使用系统默认的粤语中文音色。

## 实现结果

- 新增统一的 `speakMandarin` 播报方法。
- 明确优先选择 `zh-CN`，其次选择 `zh-SG` 普通话音色。
- 排除 `yue`、`zh-HK`、`zh-MO`、`zh-TW` 以及名称包含粤语/Cantonese 的音色。
- 预约列表、候诊队列、诊疗工作台和预约详情四个叫号入口均改用同一播报方法。
- 每次叫号前取消尚未播完的旧语音，避免连续点击产生重叠播报。

## 验证记录

- `npm.cmd run typecheck`：通过。
- `npm.cmd run build`：通过，共转换 6636 个模块；仅存在项目原有的大分块提示。
- 静态检查：四个叫号入口均调用 `speakMandarin`，业务页面不再直接创建 `SpeechSynthesisUtterance`。
- 实际音频验证：待回归。浏览器最终可用音色仍取决于操作系统安装的语音包，需要在运营后台点击叫号并听辨普通话音色。
