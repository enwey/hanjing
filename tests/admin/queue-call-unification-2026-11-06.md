# 排队分诊与接诊工作台叫号统一

日期：2026-11-06
状态：待回归（开发阶段逻辑对照和浏览器预览通过）。

发现：分诊叫号写入checked_in，工作台写入called；重呼文案和样式不同；均可能先播报后保存失败。
最终要求：以接诊工作台现有行为和文案为准，仅调整排队分诊。

- 候诊患者叫号写入called，不直接接诊；重复叫号仍显示“叫号”。
- 当前就诊中患者只播报，不写状态；按钮样式同工作台为默认描边，候诊按钮为主题色描边。
- 播报、提示、失败处理及调用顺序与现有工作台保持一致。
- 工作台及服务端没有最终改动。

验证：queue-call-parity.test.mjs 5项通过，比较两页面实际函数的调用顺序、状态参数、重复叫号、就诊中只播报及失败提示。queue-call-preview.mjs 用实际Vue页面和隔离模拟API检查两页，各3个“叫号”按钮可见且无裁切，点击候诊叫号发送called，截图已核对。未对真实患者叫号，语音被静音替代；非真实业务端到端验收。

历史：最初尝试“重新叫号”及服务端额外状态限制；用户明确纠正后全部撤回。此前queue-call/api.json是已撤回方案的API证据，不适用于当前实现。预览脚本初次存在转义错误导致空白，修正测试脚本后两页预览通过。开发自测不代替独立回归。
