# 角色与成员数据范围

状态：待回归

## 实现范围

- 角色编辑增加查看数据范围，默认个人数据。支持门店（全部/指定列表）和系统数据。
- 成员管理不再设置账号级范围。角色管理可为当前角色的成员单独调整范围或恢复继承；调整绑定角色与成员，换角色或移除后清理，不随账号转移。
- 每次鉴权读取角色与成员最新配置，不把范围固定写入登录令牌。
- 个人范围按医生关联、本人创建记录、建档、跟进及交付等已有归属查询，不以业务操作门店限制。
- 数据看板、经营报表、预约列表/详情/收费记录、患者列表/详情及订单查询接入范围过滤。全局搜索、待办统计和交付共享范围一并衔接。
- 门店全部覆盖后续新建门店，但不含无门店归属的数据；系统范围包含全部数据。
- 查看范围不赋予业务写权限，保留原业务操作门店和功能权限校验。

## 存储与迁移

- `roles.data_scope`：JSON；未配置按个人范围。首次加列时保留已有超级管理员角色的系统范围。
- `role_member_data_scopes`：以 `(role_id, admin_user_id)` 为主键，`data_scope` 保存当前角色中该成员的调整；没有记录时继承 `roles.data_scope`。
- `admin_users.data_scope`：旧字段仅为迁移保留，已清空，鉴权不读取，账号新增/编辑接口拒绝该参数。
- `admin_users.role_id` 允许空值：移除角色成员保留账号，由成员管理或角色管理重新分配角色。
- JSON：`type` 为 self/store/system，`all_stores` 为门店全部开关，`store_ids` 为指定门店 ID 数组。
- 新角色默认个人、新成员默认继承。旧成员原业务门店不自动转换为新的查看授权。
- 本地启动迁移已执行；新增列重复启动可安全跳过。
