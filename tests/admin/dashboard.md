- 日期：2026-10-22（Asia/Shanghai）。
- 方法：源码审查、5005 真实接口、3000 页面、隔离 Chrome（1440×900、375×812）。
- 数据：临时超级管理员仅用于鉴权和读取，账号与审计已清理，残留 0；未新增业务数据。
- 结论：DASH-01～05 在本轮记录范围内均回归通过。受限角色、复杂统计口径、多浏览器及真实移动设备仍未验收，不等同于数据看板全量验收。

## 【逐项测试发现】

### DASH-01：375px 下核心卡片与面板被压缩到不可用

- 状态：回归通过
- 潜在缺陷：KPI 固定四列，两处主区域固定 2:1、1:1 网格，未发现窄屏媒体查询。
- 现象：四个 KPI 各约 50px；面板宽约 28～56px；订单表格宽 524px，却位于约 42px 的面板中。
- 预期：窄屏下信息可读，区域合理换行，宽表格具备明确可用的滚动或适配方式。
- 实际结果：文档级横向滚动宽仍为 375px，但内容被极度挤压，表格溢出/裁切，无法正常阅读操作。
- 风险等级：中。
- 复现步骤：登录后台 → 打开 `/dashboard` → 将视口设为 375×812 → 查看 KPI、趋势、科室和列表。
- 观察项：平板宽度、浏览器缩放、侧栏状态可能进一步影响布局。

### DASH-02：持久化筛选值损坏后无法自动恢复

- 状态：回归通过
- 潜在缺陷：三个 `dashboard_*` 本地存储值读取后未校验枚举。
- 现象：将时间范围及趋势类型写为 `corrupt` 后刷新，出现“统计加载失败”“趋势数据加载失败”，无按钮处于选中态。
- 预期：未知或旧版本值应回退到合法默认值并正常加载。
- 实际结果：损坏值原样保留并触发非法请求，用户只能自行重新选择。
- 风险等级：中。
- 复现步骤：登录 → 将 `dashboard_filter_time`、`dashboard_chart_filter_time`、`dashboard_active_trend_type` 设为 `corrupt` → 刷新看板。
- 观察项：版本升级遗留值、扩展修改存储或存储损坏均可能触发。

### DASH-03：预约和订单为空时没有空状态

- 状态：回归通过
- 潜在缺陷：两个表格仅渲染数据行，没有空数据占位。
- 现象：无数据时表头下方直接留白。
- 预期：明确显示暂无预约/暂无订单，并与加载中、加载失败区分。
- 实际结果：用户无法判断是确实无数据、尚未加载还是渲染异常。
- 风险等级：低。
- 复现步骤：在当天无预约和订单的环境登录 → 打开看板 → 查看两张表正文。
- 观察项：KPI 同时为 0 时歧义更明显。

### DASH-04：预约或订单任一失败会清空另一个成功列表

- 状态：回归通过
- 潜在缺陷：两个请求共用一个 `try/catch`，异常时同时清空两个数组。
- 现象：预约成功后只要订单失败，预约结果也被清空，并统一提示“预约或订单列表加载失败”。
- 预期：两个独立数据源分别展示成功、空数据或失败状态。
- 实际结果：局部故障扩大为两块内容同时不可用，且不能识别具体失败源。
- 风险等级：中。
- 复现步骤：保持预约接口成功 → 令订单接口失败/超时 → 刷新看板 → 观察预约列表被一并清空。
- 观察项：本项由源码失败分支确认，未对运行服务注入故障。

### DASH-05：反复进入看板存在图表与 resize 监听累积

- 状态：回归通过
- 潜在缺陷：挂载时创建 ECharts 并注册匿名 resize 监听，卸载时未见移除监听或销毁图表。
- 现象：每次重新挂载均会新增对象和监听闭包。
- 预期：离开页面后释放已卸载页面资源。
- 实际结果：生命周期没有对应清理，长期切换可能产生冗余回调和内存占用。
- 风险等级：低。
- 复现步骤：反复在看板与其他菜单切换 → 用性能工具观察监听/实例 → 多次缩放窗口。
- 观察项：源码已确认风险，尚未完成长时内存曲线量化。

## 【遗漏的测试场景提醒】

- 有门店范围的受限角色下，各 KPI、趋势、科室、预约、订单的数据范围一致性。
- 跨日/周/月/年、闰日和上海时区零点边界。
- 支付、全额退款、跨期退款、退款中等“净收款”口径。
- 同一患者多条预约、空患者名、异常订单号、未知状态数据。
- 局部超时、500、慢响应、响应乱序的真实故障注入。
- 海量数据下接口耗时、图表渲染与内存。
- Edge、Firefox、Safari、真实平板/移动设备。
- “查看全部”跳转、返回后的筛选状态保持。

## 【本轮回归发现】

- DASH-01：375×812 下文档宽度 375px，KPI 与四个面板均为 272px，宽表格限制在面板局部横向滚动；原极端压缩现象未复现。
- DASH-02：三个缓存值写入 `corrupt` 后刷新，自动归一化为 `month`、`month`、`appointment`，本月/月按钮选中且无加载失败。
- DASH-03：运行环境无今日预约时明确显示“暂无今日预约”；订单存在数据，订单空态由模板条件路径确认。
- DASH-04：浏览器侧阻断订单接口后，仅显示“最新订单加载失败”；预约区域仍显示成功空态，未被清空为失败。
- DASH-05：连续两轮离开并重新进入看板后，页面均只存在 1 个 Canvas；源码确认卸载时移除相同 resize 处理器并销毁图表。当前 Chrome 通道不能读取监听器计数，结论限定为已记录证据范围通过。
- 真实接口：今日、本周、本月均 200，非法范围 400，无凭据 401。
- 清理：临时管理员及关联审计已清理，账号残留 0。
- 证据：[dashboard-regression-01-results.json](dashboard-regression-01-results.json)。
