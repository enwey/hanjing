## 状态规则

| 状态 | 含义 |
|---|---|
| 待验证 | 风险线索，尚未充分复现或缺少实际环境确认 |
| 待修复 | 已记录可复现问题，尚未修复 |
| 修复中 | 当前正在执行对应修复 |
| 待回归 | 修复实现完成，等待测试角色独立回归 |
| 回归不通过 | 回归仍发现原问题或相关未解决边界问题 |
| 回归通过 | 在明确记录的验证范围内通过，不等于整端验收通过 |
| 验证受阻 | 本轮无法执行验证，必须保留此前状态、阻碍原因及未测项 |

每次任务更新缺陷条目的当前状态、日期、证据和历史表；不得覆盖或删除失败历史。回归后再次复现则重新打开，标为“回归不通过”。报告中的缺陷索引与详情状态必须同步。

修复记录包含改动文件和开发自测范围；测试记录包含现象、预期、实际、风险等级、复现步骤和验证方法。测试记录不写修复方案。

没有执行过的端标“未测试”；模拟验证、真实接口验证、模拟器和真机验证必须分开标注。账号密码、令牌、密钥不写入报告。
